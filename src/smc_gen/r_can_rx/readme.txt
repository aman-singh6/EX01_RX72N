r_can_rx
=========

概要
--------
このモジュールは、CANバスを介して通信するためのインターフェースを提供します。

特徴
--------
* ポーリングモードまたは割り込みモードで動作します。
* サポート:
        - 標準および拡張CAN ID。
        - 複数のCANチャネル。
        - 簡単なテストのためのループバックモード。
        - リモートフレーム。
        - バスエラーチェック。

サポートされているMCU
--------------
* RX64Mグループ
* RX65N/RX651グループ
* RX66Tグループ
* RX66Nグループ
* RX671グループ
* RX71Mグループ
* RX72Mグループ
* RX72Nグループ
* RX72Tグループ

テストされたボード
----------------
* RSKRX64M+
* RSKRX65N+
* RSKRX65N+ 2MB
* RSKRX66N
* RSKRX66T
* RSKRX671
* RSKRX71M+
* RSKRX72M
* RSKRX72N
* RSKRX72T

直接使用される周辺機器
-------------------------
* CAN

必要なパッケージ
-----------------
* r_bsp_rx v5.20以上 (platform.hを参照)

ドライバをプロジェクトに追加する方法
----------------------------------------
* e2studio Smart Configuratorを使用するか、以下の手順に従ってください:
* r_can_rxおよびr_configフォルダをプロジェクトに追加します。
* プロジェクトのインクルードパスに'r_can_rx'ディレクトリを追加します。
* プロジェクトのインクルードパスに'r_can_rx\src'ディレクトリを追加します。
* 設定ファイル'r_can_rx_config.h'を編集して、プロジェクト用にドライバを設定します。
* FITを使用している場合は、プロジェクトにr_bsp FITモジュールを追加します。
* APIを使用するソースファイルに'#include r_can_rx_if.h'を追加します。

使用されたツールチェーン
-----------------
* Renesas RX v3.05
* GNURX 8.3.0.202305
* ICCRX 4.20.3
