r_bsp Package
=============

Overview
--------
r_bspパッケージは、コードを構築するための基盤を提供します。
スタートアップコード、iodefines、および異なるボード用のMCU情報を提供します。
r_bspパッケージは2つのフォルダーで構成されています。
'mcu'フォルダーには、MCUグループに共通のファイルが含まれています。
これらのファイルは、簡単なレジスタアクセス、CPU機能、および各MCUグループ用の'mcu_info.h'ファイルなどの機能を提供します。
'mcu_info.h'ファイルには、ボード上のMCUに関する情報が含まれており、r_bsp_config.hに記載された情報に基づいて構成されます。
'mcu_info.h'の情報は、r_bspパッケージを使用するRenesasミドルウェアの構成に役立ちます。
'board'フォルダーには、サポートされている各ボードのスタートアップコードが含まれたフォルダーがあります。
どのMCUとボードが選択されるかは、'platform.h'の設定によって決まります。
ユーザーは、自分のボードに適用されるインクルードパスのコメントを解除することで、使用するボードを選択できます。
例えば、RSK+RX62Nを使用する場合は、#include "./board/rskrx62n/r_bsp.h"のインクルードパスのコメントを解除します。
ユーザーは、自分のボードを'board'ディレクトリに追加することを推奨します。
BSPは、r_bsp_config.hファイルを使用して構成されます。
各ボードには、r_bsp_config_reference.hという名前の参照構成ファイルがあります。
ユーザーはこのファイルをプロジェクトにコピーし、r_bsp_config.hに名前を変更し、ファイル内のオプションを使用してプロジェクトのBSPを構成します。


特徴
--------
* コードを構築するための基盤を提供します。
* MCUのスタートアップコードを提供します。
* iodefine.hを通じてSFRアクセスを提供します。
* Renesasミドルウェアの構成に役立つMCUの詳細を'mcu_info.h'に保存します。
* r_bsp_config.hを通じてBSPを簡単に構成できます。
* r_bsp_config.hに部品番号の詳細を入力することで、MCUを簡単に選択できます。
* MCU例外およびバスエラー割り込みのコールバックを提供します。
* 消費電力を削減するために非接続ピンを初期化することをサポートします。
* IPLの設定、割り込みの有効化/無効化、レジスタ保護の制御など、CPU機能を制御するAPIを提供します。
